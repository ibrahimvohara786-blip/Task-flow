# Task Flow

A simple task management dashboard built with HTML, CSS, and JavaScript.

## Features

- Dashboard layout with sidebar navigation
- Task summary cards for total, completed, pending, and progress
- Add task form with priority and due date
- Task filter buttons and search input
- Responsive design for smaller screens

## Files

- `dashboard.html` - main dashboard page
- `css/dashbord.css` - dashboard styles
- `js/dasbord.js` - dashboard script
- `index.html` - landing page
- `css/styles.css` - global styles
- `js/main.js` - landing page script
- `pages/about.html` - about page
- `pages/contact.html` - contact page

## Usage

1. Open `dashboard.html` in your web browser.
2. Use the task form to add new tasks.
3. Filter tasks by status and search for tasks.
